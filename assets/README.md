# Source assets

This directory preserves the icon source pack recovered from the controlled
OneDrive working-copy handoff during T20 (2026-07-28).

- `SoftwareCenter.ico` and `SoftwareCenter.png` in the repository root are the
  desktop master files.
- The PNG variants in this directory are retained source material for future
  packaging work.
- The Android-named variants are dormant assets. Their presence does not
  reactivate or advertise the removed `web_companion`/PWA product.

Any future packaging change must select assets explicitly and keep the current
desktop and Store contracts independently testable.
