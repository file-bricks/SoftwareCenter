# Store Listing — English (en-US)

## Title
SoftwareCenter — Universal Desktop Organizer & Launcher

## Short Description
Universal desktop organization layer and launcher for apps, documents, folders, and links.

## Description
SoftwareCenter is a modern desktop organizer and universal organization layer beyond the constraints of traditional file systems. Instead of navigating cluttered start menus or disorganized desktop folders, arrange your applications, documents, project folders, scripts, and web links into clean, customizable boards and tabs tailored to your daily workflow.

## Features
- **Universal Organization Layer:** Freely organize not just apps, but any documents, project folders, scripts, and web URLs.
- **Drag & Drop Workflow:** Seamlessly drop files, shortcuts, and web addresses directly onto any board.
- **Dual View Modes:** Instantly toggle between high-visibility tile view with native system icons and compact list view.
- **Live Quick Search (Ctrl+F):** Fast filtering by name, path, or custom notes with seamless keyboard navigation.
- **Accessibility (WCAG 2.1 AA):** Complete keyboard navigation and screen reader support across all tabs and dialogs.
- **100% Local & Offline:** Zero telemetry, no cloud requirement — your workspace profile stays strictly on your computer.
